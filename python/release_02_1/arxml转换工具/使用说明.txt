一、使用 exe（给最终用户）
----------------------------------------------------------------------
双击 `arxml转换工具.exe`，选择输入 `.arxml` 文件和输出文件路径后，点击「开始转换」即可。

转换规则（其余内容不变）：
  · `<BYTE-ORDER>` 标签里凡含 `FIRST` 的，会改为 `LAST`
  · `<CATEGORY>STRING</CATEGORY>` 会改为 `<CATEGORY>utf8</CATEGORY>`


二、如何自己打包生成 exe
----------------------------------------------------------------------
1. 本机已安装 Python 环境，并在项目文件夹下打开命令行。
2. 执行：
     python build_exe.py
   若本机还没有打包所需的 PyInstaller，第一次运行会自动联网安装。
3. 生成的 exe 在本项目根目录（与 `build_exe.py` 同级），默认文件名为 `arxml转换工具.exe`。
