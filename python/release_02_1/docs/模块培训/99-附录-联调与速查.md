## 附录 A：联调培训（建议 0.5h）

按 [验收清单说明.md](../验收清单说明.md) 逐条演示：

1. 三域 Tab 切换与配置自动保存（对照 `Configuration.ini`）  
2. **左右后**全链路：DID Config + Reset-DID + CIN + SOA + CAN + XML  
3. **中央**：UART 弹窗 + 矩阵 + SOA + CAN + XML  
4. **DTC**：IO Mapping + 全链路（强调 `d_io_excel` → `io_inputs`）  
5. 打开 `log/log_时间戳/`，讲解两个子目录、TestCases.log、IO_Mapping.log  
6. （可选）打包 EXE 拷贝到干净目录验证
