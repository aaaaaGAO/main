## 关联阅读顺序（知识依赖）

```mermaid
flowchart LR
    A[00 架构] --> B[01 GUI]
    B --> J[10 配置]
    J --> C[02 IO]
    C --> G[07 CAN]
    G --> H[08 XML]
    C --> I[09 CIN]
    I --> G
    B --> D[03 DID]
    B --> E[04 Reset]
    B --> F[05 SOA]
    B --> K[06 UART]
    G --> L[11 Log]
    B --> M[12 打包]
    M --> N[99 联调]
```

- **模块 7（CAN）** 与 **2（IO）、9（CIN）** 强相关，建议连续学。  
- **模块 10（配置）** 建议在学完 **01 GUI** 后尽早学，后面各生成器都依赖 INI。  
- **模块 11（日志）** 可在跑通一次全链路后再学，便于对照真实 log 目录。

## 每册文档结构（统一模板）

1. **本模块要培训的内容** — 讲师 checklist，可打印勾选  
2. **代码位置总览（本模块「小地图」）** — **培训先讲这张表**：路径 + 一句话职责 + 主要产出  
3. **先用大白话讲清楚** — 给客户的第一段话术  
4. **整体分工 / 谁触发** — 流程图或表格  
5. **逐文件讲解** — 每个 `.py`：干什么、关键类/方法、口语解释  
6. **完整处理流程** — 逐步顺序  
7. **配置键、输入输出**  
8. **客户常问问题（备答）**  
9. **演示建议 + 预计时长**  
10. **上一册 / 下一册** 导航链接
