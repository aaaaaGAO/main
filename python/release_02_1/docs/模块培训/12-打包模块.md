# 模块 12：打包模块

## 本模块要培训的内容（讲师 checklist）

- [ ] 打包命令：在工程根执行 **`python build_exe.py`**
- [ ] 产物：**单个 EXE**，文件名 = `app.py` 里 **`TOOL_DISPLAY_NAME`**
- [ ] 打进包里的：`templates/`、`static/`、SOA 模板、Python 依赖（hidden-import）
- [ ] **不打进包**：`config/`、`input/` — 必须放在 EXE **同级**外部目录
- [ ] 日志、生成物仍写在 EXE 同级 `log/`、客户配置的 `output_dir`
- [ ] **`get_resource_path()`** 与 PyInstaller `_MEIPASS` 如何让网页资源能加载
- [ ] 默认**保留控制台窗口**（Web 服务需要；`--noconsole` 被注释）
- [ ] 工位部署清单：EXE + config 三文件 + 输入 Excel + 写权限
- [ ] 客户常问：「换电脑为什么要拷 config？」「为什么 EXE 这么大？」

---

## 代码位置总览（本模块「小地图」）

| 层级 | 路径 | 职责（一句话） |
|------|------|----------------|
| **打包脚本** | `build_exe.py` | PyInstaller 参数、add-data、hidden-import、删旧 EXE |
| **运行入口** | `app.py` | EXE 实际启动；`TOOL_DISPLAY_NAME` = EXE 文件名 |
| **资源路径** | `app.py` → `get_resource_path()` | 开发目录 vs `_MEIPASS` 模板/static |
| **工程根** | `app.py` → `get_app_path()` | EXE 同级目录 = config/log 所在 |
| **Web 工厂** | `web/__init__.py` | 打进包后仍注册蓝图 |
| **不进包** | `config/`、`input/` | 部署时放 EXE 同级（客户可改） |
| **打进包** | `templates/`、`static/`、`generators/capl_soa/templates/` | `--add-data` |

**产物**：工程根目录下 `{TOOL_DISPLAY_NAME}.exe`（单文件）

---

## 先用大白话讲清楚：打包 = 「把 Python + 网页 + 生成器打进一个 exe」

> 「开发机有 Python，客户工位可能没有。`build_exe.py` 用 **PyInstaller** 把 `app.py` 启动的整套程序（Flask、openpyxl、所有 generators）打成 **一个可双击的 EXE**。  
> **配置文件和客户 Excel 不打包**——否则每改路径都要重新编译。EXE 旁边放 `config/` 文件夹，和开发时一样。」

---

## 逐文件讲解：`build_exe.py`

### 入口与命名

| 代码 | 口语解释 |
|------|----------|
| `from app import TOOL_DISPLAY_NAME` | EXE 名与 Web 标题**同一来源**；改 `app.py` 一处即可 |
| `main_script = 'app.py'` | PyInstaller 分析入口 |
| `--onefile` | 单文件 EXE（非目录版） |
| `--distpath=.` | EXE 输出到**工程根**（与 app.py 同级） |
| `--workpath=build` / `--clean` | 临时文件在 build/，打包前清理 |

### 打进包的资源 `--add-data`

| 源路径 | 包内路径 | 用途 |
|--------|----------|------|
| `templates/` | `templates` | index.html |
| `static/` | `static` | css/js |
| `generators/capl_soa/templates/` | 同结构 | SOA Node Jinja2 模板 |

Windows 分隔符用 `;`（脚本里 `os.path.normpath` 处理）。

### hidden-import（为什么需要）

PyInstaller 静态分析找不到**动态 import** 的模块，必须手动列出，例如：

- `generators.capl_*.entrypoint` — 各生成器入口  
- `core.log_run_context`、`core.parse_table_loggers` — 日志  
- `infra.config`、`services.*` — 配置与编排  
- `tkinter`、`openpyxl`、`pypinyin` — GUI 与 Excel  

还有 `--collect-all openpyxl`、`--collect-all pypinyin` 收集数据文件。

### 打包前后脚本行为

1. 若当前目录已有同名旧 EXE → **删除**  
2. 调用 `PyInstaller.__main__.run(args)`  
3. 打印部署提醒（config/input 外部放置）

### 未启用选项（培训说明）

```python
# '--noconsole',   # 注释掉：隐藏控制台会导致看不到启动错误
# '--windowed',
```

## 运行时路径：`app.py` 与打包的配合

| 函数 | 开发模式 | 打包后 |
|------|----------|--------|
| `get_app_path()` | 工程根 | **EXE 所在目录** |
| `get_resource_path("templates")` | 工程内 templates | `sys._MEIPASS/templates` |

**客户数据路径**（config、log、output）始终相对 **EXE 目录**，不在 `_MEIPASS` 里。

## 客户常问问题（备答）

| 问题 | 建议回答 |
|------|----------|
| EXE 很大？ | 内含 Python 运行时 + Flask + openpyxl 等 |
| 杀毒软件报毒？ | PyInstaller 单文件常见误报；需企业白名单 |
| 改界面文字要重新打包吗？ | 改 templates/static 要；改 Configuration.ini **不要** |
| 能否打包 config？ | 当前设计**故意不打包**，便于现场改路径 |
| 端口被占用？ | 与开发版相同，自动找 5001+ |
