## 一、条目原文（编号 1～11）

下列为 **`2026-04-29` 之后**沟通或书面中的原文（或等价表述）摘录。

1. 运行无效转义（如启动时出现 `SyntaxWarning: invalid escape sequence` 等）。
2. 返回参数硬编码问题，error_code 定义，正常返回 code 定义等，通过模块定义。
3. 写法用装饰器，和其他模块保持统一，多处。
4. 写法？classmethod 常规使用方法。
5. 很多不需要定义为 classmethod，多处。
6. Configuration.ini 分类还是有点混乱。
7. FILTER_OPTIONS 各 option 值为什么用多行的方式，尽量和别的配置保持一致，逗号分隔的方式。
8. 没有用到的前后端路由接口等，删除。
9. `routes` 目录下面只放路由接口，其他逻辑放到合适位置。
10. didinfo 命名更改：不要用映射方式改名，在原模块上直接改（可全局替换）。
11. 写法用法，多处统一调整。
