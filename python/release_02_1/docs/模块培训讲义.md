## 架构速览（详细见 00 分册）

```
浏览器 → web/routes → services → TaskOrchestrator → generators/capl_*
                                              ↓
                                         core/* + config/*.ini
```

**三域编排**（`services/task_orchestrator.py`）：

| 域 | 顺序 |
|----|------|
| LR_REAR | did_config → did_info → cin → soa → can → xml |
| CENTRAL | uart → soa → can → xml |
| DTC | did_config → did_info → cin → soa → can → xml |
